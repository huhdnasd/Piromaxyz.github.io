Privacy Policy

Last Updated: November 2026

Information We Collect

Piroma may collect server configuration data, ticket information, moderation records, and other information necessary for providing bot functionality.

How Information Is Used

Collected information is used solely to provide, improve, and maintain Piroma's services and features.

Data Storage

Data may be stored for operational purposes, including moderation history, ticket support, logging features, and server settings.

Live bot dashboard and owner administration

The public status page displays the bot's online/offline state, uptime, and server names and aggregate member counts only for servers approved by the Piroma operator. The private dashboard uses Discord OAuth2 to verify the configured owner account. The backend uses the Discord OAuth access token only to verify that account and does not store the token. It stores owner dashboard settings, command arguments and results, and bot logs in the configured Supabase project. Dashboard sessions use secure, HTTP-only cookies and expire after eight hours. Logs are automatically deleted after 30 days and command records after 90 days by default; the operator may configure these periods. Do not send passwords, tokens, API keys, or other credentials through bot logs, settings, or commands.

Data Sharing

Piroma does not sell user data. Information is only shared when required by law or necessary for platform operation.

Data Removal Requests

Server owners may contact the Piroma team through the official support server to request removal of stored data where applicable.
